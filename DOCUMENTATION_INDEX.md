## 🎓 Key Concepts Explained

### Flat No
- **What:** Unit/apartment number (e.g., A1-101)
- **Why:** Easy identification of device location
- **Where:** Primary column in table
- **How:** Mapped from client database

### Client Mapping
- **What:** Association of devices to customers
- **Why:** Know which devices belong to whom
- **Where:** All 50 devices mapped to 6 clients
- **How:** Using modulo operator (device_id % 6)

### Status Badges
- **What:** Color-coded status indicators
- **Why:** Quick visual understanding of device state
- **Where:** "Presence" and "Status" columns
- **How:** 🟢 Online, 🔴 Offline, ⚠️ Alert

### Search & Filter
- **What:** Real-time data filtering
- **Why:** Find specific devices quickly
- **Where:** Top of table
- **How:** JavaScript event listeners on input/select
